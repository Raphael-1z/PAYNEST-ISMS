# PayNest ISMS Scope

*PayNest is a fictional company created for a portfolio project.*

## Scope statement
The ISMS of PayNest applies to the protection of information used to
provide credit, savings, deposit-taking and wallet services through its
Tamale office, mobile app, website, USSD and field agents.

## Included
- **People:** all 25 staff (office and remote, in Ghana) and field agents
- **Information:** customer personal data, accounts, wallets, transaction,
  credit and staff records
- **Systems:** in-house software, self-hosted core systems and databases,
  Microsoft 365, web front ends, office and mobile devices
- **Support:** MTN internet, Starlink backup, backup generator

## Suppliers and dependencies
Microsoft, MTN, Starlink, USSD provider, web host (if used),
independent security tester

## Exclusions
- Customers' own devices, which PayNest does not control (the app and
  the data it handles remain in scope)
- Suppliers' internal infrastructure (managing supplier security risks
  remains in scope)
